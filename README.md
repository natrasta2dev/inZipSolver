# InZip Solver

App Android : une bulle flottante s'affiche par-dessus LinkedIn. Sur la grille du Zip, touche la bulle :
l'app lit l'écran, résout la grille et dessine le chemin à suivre en transparence. Tu le traces toi-même au doigt.

## Installer
1. Ouvre la page **Releases** du dépôt depuis ton téléphone et télécharge `InZipSolver.apk`.
2. Ouvre le fichier et autorise l'installation depuis ton navigateur si Android le demande.

## Utiliser
1. Ouvre InZip Solver, touche « Lancer la bulle et ouvrir LinkedIn ».
2. Autorise l'affichage par-dessus les autres apps, puis la capture d'écran (choisis « Tout l'écran »).
3. Ouvre le Zip, touche la bulle. Touche-la à nouveau pour masquer le chemin. Appui long pour la fermer.

## Compiler
Chaque push sur `main` compile l'APK avec GitHub Actions et le publie dans la release `latest`.
